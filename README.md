# commercial_abalone_colour

Code, data, and outputs supporting the manuscript:

**"What makes a green lip? Commercial moderators of lip colour in the greenlip abalone (*Haliotis laevigata*)"**

Rebecca L. Pedler, Matthew S. Bansemer, James O. Harris, Ondi L. Crino

---

## Overview

This repository contains the full analytical pipeline used to quantify lip colour from images of farmed greenlip abalone. The study examines the effects of shade cloth coverage and abalone age on CIELAB lip colour metrics using linear mixed effects models.

**Methods note:** Colour and morphometric data in this repository were derived using the `abalone_colour_toolkit` pipeline (colour correction, lip segmentation, colour extraction, and morphometric measurement scripts).

Full method details, validation metrics, and usage instructions are available at:
https://github.com/RebeccaPedler/abalone_colour_toolkit

If you use this data or method, please cite:
Pedler et al., MethodsX (in prep/press) — full citation once available.

## Code

### `code/colour_calibration_check.R`

Checks the quality of the per-image colour calibration (Step 1b of the pipeline). Reads `data/correction_factors.csv`, summarises calibration outcomes by quality category (good / acceptable / poor) and by failure type, and plots ΔE before and after correction, saved as `figures/dE_before_after_by_quality.png`.

### `code/02_ linear_mixed_effects_model.R`

Step 2 of the pipeline: the full statistical analysis for the manuscript. Reads `data/lip_colour_commercial.csv`, cleans and re-types the data, then fits linear mixed effects models (`lme4`, `lmerTest`, `emmeans`, `performance`) examining the effects of shade cloth coverage and age on corrected CIELAB lightness, a*, b*, and chroma. Generates all figures in `figures/`, including diagnostic plots, estimated marginal means, forest plots, and colour swatches.

## Data

### `data/lip_colour_commercial.csv`

The primary analysis dataset. Contains 1,236 rows (one per abalone), including raw and calibration-corrected CIELAB lightness, a*, and b* values, per-image calibration slopes/intercepts/R², chroma, ΔE, and morphometric measurements (length, width, area, weight).

### `data/lip_colour_commercial_metadata.csv`

Column-level metadata for `lip_colour_commercial.csv`.

### `data/correction_factors.csv`

Per-image colour calibration outcomes (1,371 images), including calibration status, quality category, ColorChecker card orientation, per-channel (L*, a*, b*) correction slopes/intercepts/R², and ΔE before and after correction. Used by `colour_calibration_check.R`.

### `data/correction_factors_metadata.csv`

Column-level metadata for `correction_factors.csv`.
